Build a production-ready, mobile-first property rental marketplace called HOMZA.

TAGLINE:
"Find your place."

IMPORTANT:
HOMZA is a Uganda-focused property marketplace connecting tenants/house seekers with property owners and real-estate agents.

The platform must have TWO main user experiences:
1. TENANT / CUSTOMER
2. PROPERTY OWNER / AGENT

There will also be a separate ADMIN PANEL.

Do NOT build two separate applications. Build one application with role-based authentication and routing so the appropriate dashboard is shown based on the user's role.

==================================================
15. AUTOMATED AVAILABILITY SYSTEM
==================================================

Every active property should have an availability verification cycle.

Every 7 or 14 days:

Send owner notification:

"Is Property #104 still available?"

Actions:

[Still Available]

[Taken / Rented]

If Still Available:

Update:

last_verified_at
next_verification_at

Keep property ACTIVE.

If Taken:

Set:

status = RENTED

Archive property.

If no response:

After 48 hours:

Send warning:

"Your listing has not been verified. It will be hidden in 24 hours."

After the grace period:

Set:

status = HIDDEN

Do NOT permanently delete it.

Admin can restore the property.

Create the database structure and scheduled-job architecture needed for this.
