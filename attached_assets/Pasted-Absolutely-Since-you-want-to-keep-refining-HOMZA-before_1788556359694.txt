16. PROPERTY AVAILABILITY VERIFICATION

HOMZA must prevent outdated listings.

Every active property should periodically require verification.

Default interval:

14 days

Example notification:

> HOMZA: Is Property #104 still available?



Buttons:

Still Available

Taken/Rented

If owner confirms:

Update last_verified_at

Calculate next verification date

Keep listing ACTIVE


If owner says rented:

Mark property RENTED

Archive it


If there is no response:

After 48 hours:

> Your listing has not been verified. It will be hidden soon.



After the configured grace period:

HIDE LISTING

Do not delete the property.

Admins can restore hidden listings.

Design this system around scheduled jobs/cron so it works reliably in production.
